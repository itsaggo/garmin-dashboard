Set up your dashboard

A few quick steps. You can change any of this later in Settings.

1. Connect your Garmin data

This is Garmin's official way to share your steps, sleep, heart rate, HRV, Body Battery, stress and activities.

  1. Open Garmin Connect → Personal API and sign in.
  2. Choose Create Key, accept the terms, and pick 1 year.
  3. Copy the key (Garmin shows it only once) and paste it here.

2. Training metrics optional

Adds VO2 max, training status, training readiness and recovery time, which Garmin's official API doesn't include. It signs in the way the Garmin Connect website does, using a community library.

  • Your password is used once to sign in and is never saved. Only Garmin's sign-in token is kept.
  • If you use two-factor sign-in, you'll be asked for the code next.
  • It only reads data. Every few months Garmin may ask you to sign in again.

4. All set

Your first sync pulls up to a year of history and takes a few minutes. Charts fill in as data arrives.
